# Lovelace Octopus Energy Rate Card (Mobile-Friendly Edition)

[![hacs_badge](https://img.shields.io/badge/HACS-Custom-orange.svg)](https://github.com/hacs/integration)

Responsive, mobile-optimised custom Lovelace card for Home Assistant displaying Octopus Energy 30-minute rate prices.
Forked in repository: [Mod74/octopus-energy-rates-card-mobile](https://github.com/Mod74/octopus-energy-rates-card-mobile).

### ✨ Mobile Enhancements
- 📱 Single-column responsive collapse on mobile screens (`mobile_cols: 1`)
- 📐 Fluid column sizing with `auto_cols: true`
- 🗜️ High-density compact view (`compact_mobile: true`)
- 🏷️ High contrast pill badges with dark/light theme support
